# PowerShell / Shell 规则

1. 优先使用只读命令进行分析、搜索与检查，不得将 PowerShell 作为默认写入工具。
2. 未经用户明确授权，不得执行具有破坏性的命令，包括但不限于：`Remove-Item`、`Move-Item`、批量重命名、覆盖式写入、递归删除、进程强制结束、环境变量修改。
3. 批量文件操作前，必须先明确目标范围；不得对未限定范围的目录执行递归写入、替换或删除。
4. 不得使用 PowerShell 绕过代码修改规范。涉及仓库文件内容修改时，应遵循既有代码修改约束与补丁流程，不得以脚本批量改写代替受控修改；例外：`tools/` 下的编码 / 换行修复脚本，按 `RULES-TOOLING.md`"仓库脚本"一节使用。
5. 若仓库中已存在可复用脚本（如 `tools` 目录下脚本），优先复用现有脚本，不得重复实现等价脚本逻辑。
6. 执行构建、测试、检查类命令时，应优先选择项目文档中已定义的标准命令；不得擅自引入额外命令链、临时工具或高风险参数。
7. 若 PowerShell 命令可能影响仓库外部状态、系统环境或其他进程，必须先明确提示用户。
